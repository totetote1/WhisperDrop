# WhisperDrop

文字起こし料金は、0円。音声・動画ファイルをブラウザに読み込み、利用者の端末内で文字起こしするWebアプリです。

公開サイトはインストール・アカウント登録・APIキー不要。Mac用ダウンロード版にはNode.jsが必要です。音声や文字起こし本文をサーバーへ送信せず、TXT・SRTで保存できます。初期ベータ版です。

## 目的

Mac向けローカルアプリの仕様を、URLを開けば利用できるWeb版へ移植しました。ドラッグ＆ドロップ、モデル選択、日本語文字起こし、進捗表示、TXT・SRT出力という元の目的は維持します。

SwiftUI・Homebrew・ffmpeg・whisper.cppの外部コマンド呼び出しは使用しません。ブラウザ向けWhisperモデルをTransformers.js / ONNX Runtime Webで実行します。

## できること

- 音声・動画を1つずつ選択、またはドラッグ＆ドロップ
- 端末内で音声を16kHzモノラルに変換
- 日本語・英語・中国語・韓国語・言語自動判定
- Tiny / Base / Smallモデルの選択（多言語・量子化モデル）
- モデルダウンロード進捗、処理状態、経過時間の表示
- 文字起こしのキャンセル
- 結果の確認・TXT用テキスト編集・コピー
- TXTと時間付きSRTのダウンロード
- レスポンシブUI、キーボード操作、エラー表示

## Mac用ダウンロード版の起動・終了

1. ZIPをダウンロードして、ダブルクリックで解凍します。
2. 解凍した **WhisperDrop** フォルダを開きます。
3. **「起動.command」をダブルクリック**します。
4. ターミナルが開き、Chrome（未インストールなら標準ブラウザ）が自動で開きます。
5. 音声・動画ファイルを選んで利用します。

**`dist/index.html` を直接開いても文字起こしは動きません。必ず「起動.command」から起動してください。** ブラウザの制約のため、起動スクリプトがこのMac内だけでアクセスできるローカルサーバーを動かします。音声認識そのものはブラウザ内で行います。

「起動.command」だけを移動せず、フォルダ一式をまとめて保管してください。利用者がコマンドを入力する必要はありません。

### 初回に必要なもの

- Mac
- Node.js 18以降（すでに入っていれば追加作業不要）
- Chromeなどの対応ブラウザ
- 認識エンジン・モデル取得用のインターネット接続

Node.jsが見つからない場合は、起動画面に日本語の案内が表示されます。[Node.js公式ダウンロードページ](https://nodejs.org/ja/download)でLTSの **macOS Installer (.pkg)** を選び、インストール後に「起動.command」を開き直してください。Homebrew・Python・ffmpegは不要です。認識モデルは初回にブラウザから取得します。

### 終了方法

1. 文字起こし結果をコピー、またはTXT・SRTで保存します。
2. 起動時に開いたターミナルで **Control＋C** を押します（Command＋Cではありません）。
3. Enterキーを押して終了します。ブラウザのタブも閉じて構いません。

**使用中はターミナルを開いたままにしてください。** ブラウザを閉じただけではローカルサーバーは終了しません。再利用時も「起動.command」をダブルクリックします。

### 起動できないとき

- ブラウザが開かない：ターミナルに表示された `http://127.0.0.1:…` のURLを開いてください。
- 必要なファイルが見つからない：ZIPを解凍し直し、フォルダ内の構成を維持してください。
- macOSが開くのを止める：ダウンロード元とファイルを確認し、表示されたmacOSの案内に従ってください。実行権限を持たせてZIPに収録していますが、未署名のため環境によって警告が出る場合があります。
- ポートが使用中：別の空きポートを自動選択します。表示されるURLを利用してください。
- 初回が遅い：モデルの取得に時間がかかります。まずTinyかBaseで試してください。

## 文字起こしの使い方

1. サイトを開き、音声・動画ファイルを選びます。
2. 言語と認識モデルを選択します。まずTinyまたはBaseで試してください。
3. 「文字起こしを開始」を押します。初回はモデルをダウンロードします。
4. このタブを開いたまま完了を待ちます。
5. 内容を確認し、コピーまたはTXT・SRTを保存します。

TXT用テキストの編集はSRTへ反映しません。SRTには元の認識結果と推定タイムスタンプを出力します。保存先や同名ファイルの処理はブラウザのダウンロード設定に従います。

## 無料の範囲

アプリは文字起こしの月額料金・従量料金を請求しません。有料の文字起こしAPIを使用しないため、運営側にも音声認識API料金は発生しません。

ただし利用者の通信料・電気代・端末代は別です。サイトのホスティング・独自ドメイン・モデル配信の費用や無料枠は配信サービスの条件次第です。「運営費が無条件・無制限に0円」という保証ではありません。

## プライバシーとネットワーク

音声データはWeb Audio APIで処理し、同じ端末内のWeb Workerへ渡します。ファイルアップロードAPI、本文送信、アクセス解析、広告は実装していません。

ネットワーク接続先は主に次のとおりです。

- サイト配信元：HTML・CSS・JavaScriptを取得
- jsDelivr：Transformers.jsと必要な実行エンジンを取得
- Hugging Faceとその配信先：Whisperモデルと設定を取得

これらの配信先にはIPアドレスなど通常の接続情報が伝わります。音声や文字起こし本文は送りません。音声と本文はページ内メモリにあり、再読み込み後は復元しません。認識モデルはブラウザのキャッシュに残る場合があります。

モデルのキャッシュはブラウザによって削除される場合があります。アプリ自体のオフライン配信は未実装なので、完全オフラインでの再起動は保証しません。

## 対応環境と制限

- PCのChrome・Edgeを推奨。WebAssembly / Web Audio / module Workerが必要です。
- HTTPSまたはlocalhostで配信してください。
- MP3・WAV・M4A・MP4・MOV・AAC・FLAC・WebM・OGGを選択可能。ただし実際のデコード可否はブラウザとコンテナ内コーデック次第です。
- 音声トラックがない動画・非対応コーデックはエラーになります。
- 初期版の入力上限：1ファイル200MB・60分。上限内でも端末のメモリによって失敗する場合があります。
- 音声を一度全体デコードするため、長時間録音は分割してください。
- SmallはTiny/Baseより多くのメモリと処理時間を要します。medium / large-v3はWeb版初期モデルに含めません。
- 認識はWASMの単一スレッドで実行します。GPU高速化は未実装です。
- 処理中はタブを閉じないでください。キャンセルはWorker終了とジョブ無効化で実施します。実行中のブラウザ音声デコード自体は即時中断できません。
- 音声認識には誤りや無音時の誤生成があり得ます。固有名詞・数字・字幕時刻は確認してください。
- 話者分離・要約・辞書・複数ファイル処理・字幕編集は未実装です。

## デザイン

明るい背景、青紫のアクセント、余白を使った二列の作業画面です。左側に入力と設定、右側に結果を配置し、モバイルでは縦に並べます。大きな宣伝ページを挟まず、すぐにファイルを選択できます。

## 開発

Node.js 18以降で、追加パッケージのインストールなしで起動できます。

```sh
npm start
```

Macでは「起動.command」も同じサーバーを使用します。通常は `http://127.0.0.1:4173` で起動し、使用中なら空きポートを選びます。`WHISPERDROP_NO_OPEN=1` を設定すると、開発・検証時のブラウザ自動起動を抑止できます。

```sh
npm run check
```

ビルドは不要です。バージョン固定したTransformers.js 3.8.1をCDNから取得します。将来的に依存ライブラリを自前配信する場合は、モデル配信先も含めて検証してください。

## ファイル構成

```text
dist/
  index.html   画面
  style.css    デザイン
  app.js       ファイル・音声変換・UI制御
  worker.js    端末内のWhisper実行
  format.js    TXT/SRT用の時刻整形
  favicon.svg
起動.command  Mac用ダブルクリック起動
scripts/serve.mjs  ローカルサーバー
README.md
package.json
.openai/hosting.json  Sites公開設定
```

## デプロイ・GitHub公開

`dist/` を静的サイトとしてHTTPSで配信します。サーバーで音声認識を動かす必要はありません。

Sitesでは `.openai/hosting.json` の `static.directory` に `dist` を指定します。GitHub Pagesを使う場合は、PagesのActionsで `dist/` を公開する構成を追加できます。相対パスのためリポジトリ配下URLにも対応します。

GitHubにはこのソースとREADMEを公開します。元のFC説明会の音声、文字起こし、資料、個人情報、認証情報を含めないでください。Sitesのソース保管と、利用者のGitHubアカウントへの公開は別の操作です。
